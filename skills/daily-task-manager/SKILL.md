# pbrain Daily Task Manager

Maintain an actionable task system without turning project context into a giant backlog.

## Workflow

1. Determine whether the task view is local project or global portfolio.
2. Read the relevant local `TODO & Ideas.md` and active `WORKSTREAM.md`.
3. Check whether the global pbrain exists at `C:\Users\harsha.konga\Project Brain\`.
4. If global pbrain exists, read global `TASKS.md` and route cross-project tasks/dependencies there.
5. If global pbrain does not exist, keep task management local.
6. Normalize tasks into P0-P3 priorities.
7. Remove or archive completed items only when supported by evidence.
8. Link each task back to its project/workstream source.

## Rules

- Keep local TODOs short and near-term.
- Keep detailed rationale in workstream ledgers.
- Use global `TASKS.md` for cross-project prioritization.
- Do not invent owners or deadlines.
- Do not fail if the global pbrain is absent; local task mode is valid.
